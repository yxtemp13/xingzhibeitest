# 贪吃蛇小游戏

这是一个使用原生 HTML、CSS 和 JavaScript 编写的贪吃蛇小游戏。玩家可以使用方向键控制蛇移动，吃到食物会增长长度并提高速度。

## 功能特性
- 光滑渐变风格的棋盘与蛇身渲染。
- 支持开始、暂停与重新开始按钮操作。
- 随着得分增加自动加速，最高速度受限，确保挑战性和可玩性。
- 使用键盘方向键控制方向，并在蛇头展示简单的表情细节。

## 本地运行 / 部署
由于这是一个纯静态网页，只需要任何静态文件服务器即可部署，例如：

```bash
python -m http.server 8000
```

运行命令后，打开浏览器访问 [http://localhost:8000](http://localhost:8000) 即可游玩。

如果要部署到线上，可将 `index.html` 上传到任何静态网站托管平台（如 GitHub Pages、Vercel、Netlify 等）。
